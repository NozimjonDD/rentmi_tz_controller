# 3-9 Chat (ijarachi)

**Manba:** [R4 · 4. Bajariladi](https://rentmi.atlassian.net/wiki/spaces/~71202079d067c95f7a441fb0ca94a54260ce25/pages/29425665) · [R5 · 4. Bajariladi](https://rentmi.atlassian.net/wiki/spaces/~71202079d067c95f7a441fb0ca94a54260ce25/pages/43843819)

## Joriy talablar

- Chat tugmasini tepaga, bildirishnoma tugmasi yoniga chiqarish (unread badge bilan); tepadagi profil olib tashlanadi `R5`
  > ⚠ Konflikt: R4 da — Chat bottom nav tab (pufakcha ikona)
- Har bir chat kartasi: avatar + online indikator (yashil nuqta), ism, oxirgi xabar, mulk mini-kartasi `R4`
- O'qilmagan xabarlar badge (raqam) `R4`
- Delivery status: ✓ yuborildi, ✓✓ o'qildi `R4`
- Chat detail: mulk kartasi header'da, sana separator, xabar thread `R4`
- Matn xabar yuborish (matn maydoni + yuborish tugmasi) `R4`
- Rasm yuborish (paperclip ikona, 2-ustun grid preview) `R4`
- Xabar uzoq bosish menyusi: Qaytarish | Tahrirlash | Nusxa olish | O'chirish `R4`
- Multi-select rejim: checkbox + mass copy/delete, 'O'chirish' tasdiqlash modali `R4`
- Header: search (xabar qidirish) + 3-nuqta menyu (Telefon qilish | Block qilish) `R4`
- 3-nuqta menyu → 'Block qilish' bosilganda tasdiqlash bottom sheet `R4`
- Sabab checkboxlari: Uy rasmda ko'rsatilganday emas | Narx e'londa ko'rsatilganday emas | Boshqa (+ textarea) `R4`
- 'Ushbu shaxsning e'lonlarini ko'rmoqchimasman' tugmasi `R4`
- Bloklangandan so'ng o'sha uy egasiga tegishli e'lonlar feeddan chiqariladi `R4`
- Xavfsizlik xabari: "faqat platforma orqali muloqot qiling" bloki chat/so'rov oqimida `R5`
- Chat so'rov tasdiqlanmagan bo’lsa xam ochiladi; rad etilgan so'rovlarda chat va telefon qilish yo'q `R4 · IJ-C1 BQ-1`
  > ❓ Ichki nomuvofiqlik: R4 · IJ-C1 da — Ijarachi tizimga kirgan; kamida bitta tasdiqlangan so'rov mavjud (chat faqat tasdiqlangandan keyin ochiladi)
  >
  > Izoh: ko'pchilik joyda (IJ-C1 BQ-1, UE-C1 BQ-1, IJ-R1 BQ-7) chat tasdiqlanmagan so'rovda ham ochiladi; bitta sahifa ichida zid — hal qilinmagan (N4).
