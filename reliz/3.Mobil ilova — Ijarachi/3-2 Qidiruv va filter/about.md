# 3-2 Qidiruv va filter

**Manba:** [R3 · Bajariladi](https://rentmi.atlassian.net/wiki/spaces/~71202079d067c95f7a441fb0ca94a54260ce25/pages/27721729) · [R5 · 4. Bajariladi](https://rentmi.atlassian.net/wiki/spaces/~71202079d067c95f7a441fb0ca94a54260ce25/pages/43843819)

## Joriy talablar

- Qidiruv satri (search bar) — real-time qidiruv, qidiruv tarixi saqlash `R3`
- Grid / List ko'rinishni almashtirish tugmasi `R3`
- Filter bottom sheet — ijara turi, lokatsiya (3 darajali: viloyat → tuman → ko'p tanlash, e'lonlar soni ko'rsatish), narx range slider (So'm/Dollar), xonalar soni, maydon, qavat, mulk turi chips, jonivorlar checkbox `R3`
- Narx maydonlari va slider qiymatlarini yaxlitlash: so'mda — mln qadam, dollarda — 100$ qadam; so'm/dollar toggle `R5`
- "Filterni saqlash" va "Filterni tozalash" tugmalari; saqlangan filtrlar mantig'ini qayta ko'rib chiqish `R5`
- E'lonlar ro'yxati sahifasi — grid/list/single card ko'rinishlari, xarita tugmasi, filter tugmasi `R3`
