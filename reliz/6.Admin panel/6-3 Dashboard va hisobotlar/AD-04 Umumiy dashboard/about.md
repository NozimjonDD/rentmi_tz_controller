# AD-04 — Umumiy dashboard

| **AD-04 — Umumiy dashboard** |
| --- |
| **Aktyor** | Administrator |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Administrator admin veb-ilovasiga kiradi — dashboard bosh sahifa. |
| **Bajarish tartibi** | Administrator tizimga kirganda avtomatik dashboard sahifasi ochiladi; 2) Dashboard real-time ma’lumotlarni ko’rsatadi (30 sek da bir yangilanadi); 3) Ko’rsatkichlar bloklari:    — Yangi ro’yxatlar: bugun, shu hafta, shu oyda ro’yxatdan o’tganlar soni;    — Faol e’lonlar: jami faol e’lonlar soni;    — Moderatsiya navbati: hozir kutayotgan e’lonlar soni (rangli signal: 0–5 yashil, 6–20 sariq, 21+ qizil);    — Bugungi so’rovlar: yangi ijara so’rovlari soni;    — Skoring sotuvlari: bugungi to’liq hisobot xaridlari soni; 4) So’nggi faoliyat lenta: oxirgi 10 ta muhim amal (yangi ro’yxat, tasdiqlangan e’lon, bloklangan foydalanuvchi va boshqa); 5) Tezkor havolalar: Moderatsiya navbatiga o’tish, Ijarachilar ro’yxati, Uy egalari ro’yxati, Hisobotlar; 6) Ko’rsatkichga bosib tegishli bo’limga o’tish mumkin. |
| **Vaqt reglamenti** | Dashboard yuklanishi ≤ 3 sek; real-time yangilanish har 30 sek. |
| **Kiruvchi ma'lumotlar** | Administrator identifikatori. |
| **Chiquvchi ma'lumotlar** | Real-time metrikalar, so’nggi faoliyat lenta, tezkor havolalar. |
| **Kengaytmalar** | Tarmoq uzilsa — oxirgi kesh ko’rsatiladi va “Real-time emas” ogohlantirishi chiqadi; yangilanish xatosi bo’lsa — “Qayta yuklash” tugmasi paydo bo’ladi. |
