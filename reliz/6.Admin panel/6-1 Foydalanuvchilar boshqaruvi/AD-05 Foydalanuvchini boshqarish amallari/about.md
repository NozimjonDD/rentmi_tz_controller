# AD-05 — Foydalanuvchini boshqarish amallari

| **AD-05 — Foydalanuvchini boshqarish amallari** |
| --- |
| **Aktyor** | Administrator |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Administrator AD-01 yoki AD-02 ro’yxatidan foydalanuvchini tanlagan. |
| **Bajarish tartibi** | Foydalanuvchi profili sahifasi ochiladi — quyidagi ma’lumotlar birgalikda ko’rsatiladi:    — Shaxsiy ma’lumotlar: ism, telefon, MyID holati, ro’yxatdan o’tgan sana;    — Ijarachi uchun: Rentmi ball, skoring xulosasi (light), ijara so’rovlari tarixi;    — Uy egasi uchun: e’lonlar ro’yxati (holat va sana bilan), moderatsiya tarixi;    — Hisob holati va tarixi (kim, qachon, nima o’zgartirgan); 2) Administrator quyidagi amallari bajarishi mumkin:  BLOKLASH / AKTIVLASHTIRISH:    — “Bloklash” tugmasi → sabab kiritish (majburiy) → tasdiq → hisob “Bloklangan” holatiga o’tadi;    — Bloklangan foydalanuvchi tizimga kira olmaydi;    — “Aktivlashtirish” → hisob qayta “Faol” holatiga o’tadi;  BLACKLIST QO’SHISH / OLIB TASHLASH:    — “Blacklistga qo’shish” → sabab va izoh kiritish (majburiy) → tasdiq;    — Blacklistdagi foydalanuvchi ro’yxatdan o’ta olmaydi;  PROFILNI TAHRIRLASH (favqulodda):    — Faqat ism va telefon raqamini o’zgartirish mumkin;    — Pasport va identifikatsiya ma’lumotlari tahrirlanmaydi;  3) Barcha amallar audit jurnaliga yoziladi: kim bajargan, qachon, sabab; 4) Foydalanuvchiga amal haqida push bildirishnoma yuboriladi. |
| **Vaqt reglamenti** | Profil yuklanishi ≤ 3 sek; amal bajarish ≤ 3 sek; bildirishnoma ≤ 10 sek. |
| **Kiruvchi ma'lumotlar** | Foydalanuvchi ID, tanlangan amal, sabab / izoh matni. |
| **Chiquvchi ma'lumotlar** | Yangilangan foydalanuvchi holati; audit yozuvi; bildirishnoma. |
| **Kengaytmalar** | Blacklistga qo’shilayotgan foydalanuvchining faol so’rovlari yoki shartnomalari bo’lsa — ogohlantirish va mavjud majburiyatlar ro’yxati ko’rsatiladi, administrator qaror qiladi; administrator o’z hisobini o’zi bloklashga urinsa — amal bloklanadi; bir foydalanuvchini bir vaqtda ikki administrator tahrirlasa — konflikt xabari va qayta yuklash taklifi. |
