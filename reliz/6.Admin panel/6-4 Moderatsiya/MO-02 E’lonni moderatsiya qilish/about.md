# MO-02 — E’lonni moderatsiya qilish

| **MO-02 — E’lonni moderatsiya qilish** |
| --- |
| **Aktyor** | Moderator |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Moderator MO-01 navbatidan e’lonni tanlagan; e’lon “Moderatsiya kutmoqda” yoki “Tuzatish kutmoqda” holatida. |
| **Bajarish tartibi** | Moderator e’lon tafsilotlarini ko’rib chiqadi:    — Barcha fotolar galereya ko’rinishida;    — Mulk parametrlari (tur, xonalar, maydon, qavat, narx);    — Joylashuv (Google Maps da belgilangan nuqta);    — Tavsif matni;    — Uy egasi profili: ismi, MyID holati, ro’yxatdan o’tgan sana, boshqa e’lonlar soni; 2) Moderator uchta qarordan birini qabul qiladi:  TASIDQLASH:    — “Tasdiqlash” tugmasi bosiladi;    — Tasdiqlash dialogi: “E’lonni tasdiqlaysizmi?”;    — Tasdiqlangach e’lon “Faol” holatiga o’tadi;    — Uy egasiga push bildirishnoma: “E’loningiz tasdiqlandi”;    — Audit jurnaliga yozuv kiritiladi;  RAD ETISH:    — “Rad etish” tugmasi bosiladi;    — Moderator rad etish sababini kiritishi shart (matn maydoni, majburiy - 3 xil tilda, moderatorga komentariylar oldindan kiritib qo’yilgan shablonlar asosida tanlash uchun ko’rsatilsin);    — Tasdiqlangach e’lon “Rad etildi” holatiga o’tadi;    — Uy egasiga push bildirishnoma + rad etish sababi yuboriladi;    — Audit jurnaliga yozuv kiritiladi;  TUZATISH TALABI:    — “Tuzatish talab qilish” tugmasi bosiladi;    — Moderator tuzatish izohini kiritadi (nima to’g’irlandirishni aniq ko’rsatadi);    — E’lon “Tuzatish kutmoqda” holatiga o’tadi;    — Uy egasiga push bildirishnoma + izoh yuboriladi;    — Audit jurnaliga yozuv kiritiladi; 3) Qarordan so’ng moderator avtomatik navbatdagi e’longa o’tadi yoki ro’yxatga qaytadi. |
| **Vaqt reglamenti** | Tafsilotlar yuklanishi — ≤3 sek; qaror saqlash — ≤3 sek; bildirishnoma yuborish — ≤10 sek. |
| **Kiruvchi ma'lumotlar** | E’lon ID, qaror (tasdiqlash/rad/tuzatish), sabab yoki izoh matni. |
| **Chiquvchi ma'lumotlar** | Yangilangan e’lon holati; audit yozuvi; uy egasiga bildirishnoma. |
| **Kengaytmalar** | Bir e’lonni bir vaqtda ikki moderator ko’rib chiqsa — birinchi qaror qabul qilganda ikkinchisiga “Bu e’lon allaqachon ko’rib chiqildi” xabari chiqadi; rad etish sababini bo’sh qoldirib bo’lmaydi — “Yuborish” tugmasi faol bo’lmaydi; moderator o’z qaroriga 5 daqiqa ichida izoh qo’sha oladi (audit jurnaliga qo’shimcha yozuv bilan). |
