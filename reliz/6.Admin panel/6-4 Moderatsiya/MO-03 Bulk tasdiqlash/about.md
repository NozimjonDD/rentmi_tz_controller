# MO-03 — Bulk tasdiqlash

| **MO-03 — Bulk tasdiqlash (10 tagacha)** |
| --- |
| **Aktyor** | Moderator |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Moderator MO-01 navbatida va kamida 2 ta e’lon “Moderatsiya kutmoqda” holatida. |
| **Bajarish tartibi** | Moderator ro’yxatda “Bulk tanlash” rejimini yoqadi; 2) Har bir e’lon oldida belgilash qutisi (checkbox) paydo bo’ladi; 3) Moderator tasdiqlash uchun e’lonlarni belgilaydi; 4) Tanlangan e’lonlar soni ko’rsatiladi: “Tanlandi: 7/10”; 5) “Barcha tanlanganlarni tasdiqlash” tugmasi bosiladi; 6) Tasdiqlash dialogi: “\[N\] ta e’lonni tasdiqlaysizmi? Bu amal qaytarib bo’lmaydi.”; 7) Tasdiqlangach barcha tanlangan e’lonlar “Faol” holatiga o’tadi; 8) Har bir uy egasiga alohida bildirishnoma yuboriladi; 9) Audit jurnaliga barcha e’lonlar uchun yozuv kiritiladi; 10) Progress indikator ko’rsatiladi (masalan, “7/7 tasdiqlandi”). |
| **Vaqt reglamenti** | Bulk tasdiqlash (10 ta) — ≤15 sek; progress indikator real vaqtda yangilanadi. |
| **Kiruvchi ma'lumotlar** | Tanlangan e’lonlar ID ro’yxati, qaror (tasdiqlash). |
| **Chiquvchi ma'lumotlar** | Barcha tanlangan e’lonlar “Faol” holati; audit yozuvlari; bildirishnomalar. |
| **Kengaytmalar** | tanlangan e’lonlar orasida “Tuzatish kutmoqda” holati bo’lsa — bu e’lonlar bulk dan olib tashlanadi va alohida ogohlantirish ko’rsatiladi; jarayon davomida tarmoq uzilsa — muvaffaqiyatli tasdiqlangan e’lonlar saqlanadi, qolganlar uchun xatolik xabari va qayta urinish imkoniyati. |
