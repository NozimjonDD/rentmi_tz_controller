**MODERATOR USE CASELARI**

MO-01 — Moderatsiya navbatini ko’rish

| **MO-01 — Moderatsiya navbatini ko’rish** |
| --- |
| **Aktyor** | Moderator |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Moderator admin veb-ilovasiga kirgan va moderator roliga ega. |
| **Bajarish tartibi** | Moderator admin panelga kirganda yoki “Moderatsiya” bo’limini ochganda moderatsiya navbati avtomatik yuklanadi; 2) Tizim “Moderatsiya kutmoqda” va “Tuzatish kutmoqda” holatidagi barcha e’lonlarni ko’rsatadi; 3) Ro’yxatda eng eski e’lon birinchi bo’lishi tartibida (FIFO) saralanadi; 4) Har bir e’lon kartochkasida quyidagilar ko’rsatiladi: e’lon rasmi (birinchi foto), mulk nomi va manzili, mulk turi, narx, uy egasi ismi , e’lon yuborilgan sana va kutish vaqti (necha kun / soat), holat badge; 5) Ro’yxat tepasida umumiy navbat hajmi ko’rsatiladi (“Moderatsiya kutmoqda: 12”); 6) Qidirish va filtr imkoniyati mavjud: uy egasi ismi, mulk turi, hudud, sana oralig’i bo’yicha; 7) E’longa bosib MO-02 use casega o’tiladi. |
| **Vaqt reglamenti** | Navbat yuklanishi ≤ 3 sek; filtr qo’llash ≤ 1 sek. |
| **Kiruvchi ma'lumotlar** | Moderator identifikatori va roli. |
| **Chiquvchi ma'lumotlar** | Moderatsiya kutayotgan e’lonlar ro’yxati: e’lon ID, nomi, uy egasi, holat, kutish vaqti. |
| **Kengaytmalar** | E’lonlar yo’q bo’lsa — “Navbat bo’sh” holat ko’rsatiladi; filtr bo’yicha hech narsa topilmasa — natija yo’qligi xabari; navbat soni real-time yangilanadi (30 sek). |
