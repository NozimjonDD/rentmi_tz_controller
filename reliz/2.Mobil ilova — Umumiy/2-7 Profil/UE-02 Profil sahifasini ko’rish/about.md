# UE-02 — Profil sahifasini ko’rish

| **UE-02 — Profil sahifasini ko’rish** |
| --- |
| **Aktyor** | Uy egasi |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Foydalanuvchi tizimga kirgan va uy egasi roliga ega. |
| **Bajarish tartibi** | Foydalanuvchi navigatsiyadan “Profil” bo’limini ochadi; 2) Tizim foydalanuvchi profilini yuklab ko’rsatadi; 3) Ekranda quyidagilar ko’rinadi: profil rasmi (yoki boshlang’ich harflar avatar), to’liq ismi, telefon raqami, rol badge (“Uy egasi”), MyID identifikatsiya holati (tasdiqlangan / tasdiqlanmagan), ro’yxatdan o’tgan sana; 4) “Tahrirlash” tugmasi orqali UE-03 use casega o’tiladi; 5) Identifikatsiya holati “tasdiqlanmagan” bo’lsa — MyID ga o’tish uchun banner ko’rsatiladi; 6) “Chiqish” tugmasi pastda joylashgan. |
| **Vaqt reglamenti** | Profil sahifasi yuklanish ≤ 2 sek. |
| **Kiruvchi ma'lumotlar** | Foydalanuvchi identifikatori. |
| **Chiquvchi ma'lumotlar** | Foydalanuvchi profil ma’lumotlari: ism, telefon, rol, identifikatsiya holati, ro’yxatdan o’tgan sana. |
| **Kengaytmalar** | Tarmoq uzilsa — oxirgi kesh ko’rsatiladi va ogohlantirish banner chiqadi; profil rasmi yuklanmasa — boshlang’ich harflar avatar ko’rsatiladi. |
