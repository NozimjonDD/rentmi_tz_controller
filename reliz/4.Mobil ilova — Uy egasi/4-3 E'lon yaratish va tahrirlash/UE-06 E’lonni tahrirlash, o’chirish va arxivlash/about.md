# UE-06 — E’lonni tahrirlash, o’chirish va arxivlash

| **UE-07 — E’lonni tahrirlash, o’chirish va arxivlash** |
| --- |
| **Aktyor** | Uy egasi |
| **Turi** | Asosiy |
| **Ishga tushirish shartlari** | Foydalanuvchi “Mulklarim” ro’yxatidan e’lon tafsilotiga kirgan. |
| **Bajarish tartibi** | TAHRIRLASH: 1) Foydalanuvchi e’lon tafsilotida “Tahrirlash” tugmasini bosadi; 2) E’lon yaratish ekraniga o’xshash tahrirlash ekrani ochiladi — mavjud ma’lumotlar to’ldirilgan; 3) Narx, tavsif, fotolar, shartlar o’zgartirilishi mumkin; 4) Joylashuv va mulk turi o’zgartirilsa — e’lon qayta moderatsiyaga yuborilishi haqida ogohlantirish ko’rsatiladi; 5) “Saqlash” bosilganda:    — Kichik o’zgarish (narx, tavsif): e’lon “Faol” holatda qoladi;    — Jiddiy o’zgarish (joylashuv, tur): e’lon “Moderatsiya kutmoqda” holatiga o’tadi;  ARXIVLASH: 1) Foydalanuvchi “Arxivlash” tugmasini bosadi; 2) Tasdiqlash dialogi: “E’lon ko’rinmay qoladi. Keyinchalik qayta faollashtirish mumkin.”; 3) Tasdiqlangach e’lon “Arvixda” holatiga o’tadi va katalogdan ko’rinmaydi; 4) Arxivlangan e’lonni qayta faollashtirish — e’lon moderatsiyaga yuboriladi;  O’CHIRISH: 1) Foydalanuvchi “O’chirish” tugmasini bosadi; 2) Tasdiqlash dialogi: “E’lon butunlay o’chiriladi. Bu amalni qaytarib bo’lmaydi.”; 3) Tasdiqlangach e’lon tizimdan o’chiriladi (soft delete — ma’lumotlar bazasida audit uchun saqlanadi). |
| **Vaqt reglamenti** | Saqlash ≤ 3 sek; arxivlash / o’chirish ≤ 2 sek; qayta moderatsiyaga yuborish ≤ 3 sek. |
| **Kiruvchi ma'lumotlar** | O’zgartirilgan ma’lumotlar; tasdiqlash buyrug’i (arxivlash / o’chirish uchun). |
| **Chiquvchi ma'lumotlar** | Yangilangan e’lon yoki o’chirilgan / arxivlangan holat; muvaffaqiyat xabari. |
| **Kengaytmalar** | Moderatsiya kutayotgan e’lonni tahrirlash mumkin emas — “Moderator ko’rib chiqmoqda” xabari ko’rsatiladi; bloklangan e’lonni foydalanuvchi o’chirish yoki tahrirlash mumkin emas — administrator bilan bog’lanish taklif qilinadi; o’chirish tugmasi faqat Qoralama va Rad etildi holatidagi e’lonlar uchun ko’rsatiladi; Faol va Ijaraga berilgan e’lonlar uchun faqat Arxivlash mumkin |
