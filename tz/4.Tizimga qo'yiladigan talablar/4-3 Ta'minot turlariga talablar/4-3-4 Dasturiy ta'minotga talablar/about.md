4.3.4. Dasturiy ta'minotga talablar

Qo'shimcha dasturiy ta'minot ro'yxati:

- Operatsion tizim (server): Linux (Ubuntu LTS yoki shunga o'xshash);
- Ma'lumotlar bazasi: PostgreSQL 14.x yoki undan yuqori;
- Keshlash: Redis 6.x yoki undan yuqori;
- Xabar navbati: RabbitMQ yoki Redis Streams;
- Obyektli saqlash: S3-mos keluvchi saqlash xizmati (mahalliy bulutli provayder tomonidan);
- Veb-server/Reverse proxy: Nginx;
- Konteynerlashtirish: Docker;
- Orkestratsiya (zaruratga ko'ra): Kubernetes yoki Docker Swarm;
- Monitoring: Prometheus + Grafana yoki shunga o'xshash vositalar;
- CI/CD: GitLab CI, GitHub Actions yoki shunga o'xshash.

Ishlab chiqiladigan dasturiy ta'minot stack:

- Backend: Python (3.10 yoki undan yuqori) Django yoki FastAPI frameworki asosida;
- Mobil ilova (iOS va Android): Flutter (Dart tilida), kamida 3.x versiyasi;
- Administrator veb-interfeysi: zamonaviy SPA frameworki (React, Vue yoki shunga o'xshash) orqali;
- API hujjatlash: OpenAPI/Swagger.

Dasturiy vositalarning texnik vositalar va operatsion muhitdan mustaqilligi:

- Tizim konteynerlashtirilgan arxitektura asosida quriladi, bu uni turli operatsion tizimlar va muhitlarga ko'chirish imkoniyatini beradi;
- Dasturiy ta'minot bulutli va lokal muhitlarda ishlash qobiliyatiga ega bo'ladi.
