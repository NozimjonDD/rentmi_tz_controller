4.3.3. Lingvistik ta'minotga talablar

Dasturlash tillari:

Yuqori darajadagi dasturlash tillari qo'llaniladi: Python (backend), Dart (mobil ilova — Flutter doirasida), SQL (ma'lumotlar bazasi uchun), JavaScript/TypeScript (administrator veb-interfeysi uchun).

Foydalanuvchi va tizim o'zaro aloqasi tillari:

Foydalanuvchi interfeysi quyidagi tillarni qo'llab-quvvatlaydi:

- o'zbek tili (lotin alifbosida);
- o'zbek tili (kirill alifbosida);
- rus tili;
- ingliz tili.

Foydalanuvchi birinchi kirishda interfeys tilini tanlaydi va keyinchalik sozlamalarda o'zgartirishi mumkin.

Ma'lumotlarni kiritish/chiqarish va boshqarish tillari:

- Ma'lumotlarni boshqarish tili: SQL (PostgreSQL dialekti);
- API darajasidagi so'rovlar: REST (JSON);
- Mobil ilova va backend o'rtasida: REST + WebSocket (real vaqt rejimidagi bildirishnomalar uchun).
