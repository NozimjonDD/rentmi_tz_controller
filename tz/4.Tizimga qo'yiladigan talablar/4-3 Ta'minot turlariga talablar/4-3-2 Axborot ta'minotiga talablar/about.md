4.3.2. Axborot ta'minotiga talablar

Ma'lumotlarning tarkibi, tuzilishi va tashkillashtirish usullari:

- Tizim ma'lumotlari yagona relyatsion ma'lumotlar bazasida saqlanadi;
- Fayl ma'lumotlari (fotosuratlar, hujjatlar) obyektli saqlash tizimida saqlanadi;
- Tez-tez ishlatiladigan ma'lumotlar keshlash qatlami orqali tezlashtiriladi;
- Ma'lumotlar tuzilishi normallashtirilgan shaklda tashkil etiladi, referensial yaxlitlik mexanizmlari qo'llaniladi.

Komponentlar orasidagi axborot almashish:

- Ichki komponentlar orasidagi axborot almashish RESTful API va ichki xabar navbatlari orqali amalga oshiriladi.

Smejali tizimlar bilan axborot muvofiqligi:

- Tashqi tizimlar bilan integratsiya RESTful API asosida (batafsil 4.1.2 bandida);
- Ma'lumot formatlari tashqi tizim spetsifikatsiyasiga mos ravishda moslashtiriladi.

Klassifikatorlar va unifikatsiyalangan hujjatlardan foydalanish:

- "RENTME" MChJning ichki ma'lumotnomalari va klassifikatorlari qo'llaniladi (batafsil 4.1.11 bandida).

Kiruvchi va chiquvchi ma'lumotlar formati:

- Kiruvchi ma'lumotlar API orqali: JSON (REST);
- Chiquvchi ma'lumotlar: JSON (API), PDF (hisobotlar), XLSX/CSV (eksport).

Tizim tomonidan shakllantirilgan hujjatlarga yuridik kuch berish:

- Ijara shartnomalari va boshqa yuridik ahamiyatga ega hujjatlar (3-bosqichda) elektron imzo bilan tasdiqlanadi;
- Hujjatlar O'zbekiston Respublikasining "Elektron raqamli imzo to'g'risida"gi qonun talablariga muvofiq rasmiylashtiriladi;
- Tranzaksiyalar va yuridik ahamiyatga ega operatsiyalar timestamp va audit iz bilan mustahkamlanadi.
