4.1.3.2. Foydalanuvchilarning rollari va ish qoidalari

Tizimda quyidagi foydalanuvchi rollari belgilanadi:

| Rol | Tavsifi va asosiy vakolatlari |
| --- | --- |
| Ijarachi | Ko'chmas mulk obyektlarini ijaraga olish niyatidagi mobil ilova orqali ro'yxatdan o'tgan va identifikatsiyadan o'tgan foydalanuvchi. E'lonlarni qidirish, ijara so'rovlarini yuborish, o'z skoring ko'rsatkichini ko'rish, to'lovlarni amalga oshirish imkoniyatiga ega. |
| Uy egasi | Ko'chmas mulk obyektlarini ijaraga beruvchi mobil ilova orqali ro'yxatdan o'tgan va identifikatsiyadan o'tgan foydalanuvchi. E'lonlarni joylashtirish va boshqarish, ijara so'rovlarini ko'rib chiqish, ijarachining skoring ko'rsatkichini ko'rish imkoniyatiga ega. |
| Administrator | Tizim faoliyatini web admin portali orqali to'liq boshqaruvchi foydalanuvchi. Barcha operatsiyalar va ma'lumotlar bo'yicha kirish huquqiga ega. |
| Moderator | E'lonlarni web admin portali orqali tekshirish va tasdiqlashga javobgar foydalanuvchi. E'lonlarni nazorat qilish va soxta e'lonlarni bloklash vakolatiga ega. |
| Call-markaz operatori | Foydalanuvchi murojaatlarini web admin portali orqali qabul qilish va qo'llab-quvvatlash bo'yicha javobgar xodim. Faqat ko'rish (o'qish) huquqiga ega. |
| Texnik qo'llab-quvvatlash xodimi | Foydalanuvchi murojaatlarini web admin portali orqali ko'rib chiqish va javob berish bilan shug'ullanuvchi xodim. Admin web paneli orqali ticket boshqaruvi, eskalatsiya va holat yangilash huquqiga ega. Analitika ma'lumotlariga cheklangan (anonimlashtirilgan) kirish; tizim jurnallariga faqat o'qish rejimida kirish mumkin. |
| Ro'yxatdan o'tmagan foydalanuvchi (guest) | Ro'yxatdan o'tmasdan cheklangan imkoniyatlar bilan mobil ilovani ko'rib chiqayotgan potensial ijarachi yoki uy egasi ro’lidagi foydalanuvchi. Faqat ayrim e'lonlarni ko'rish va tizim bo'yicha umumiy ma'lumot olish imkoniyatiga ega. |

Foydalanuvchi rollari va ularning kirish huquqlari tizim ma'lumotlari obyektlariga nisbatan Konsepsiya hujjatidagi kirish huquqlarini taqsimlash matritsasiga mos ravishda belgilanadi.
